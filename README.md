# Smatrix_4d_primal_gapped_singlet

This Mathematica code constructs an ansatz for a crossing symmetric amplitude, it computes the partial wave projection, and builds the semidefinite program ready for SDPB.

## School example

A small Z2-even 4D bootstrap runner is available in
`school/notebooks/`. The large precomputed integral cache is distributed as a
GitHub Release asset, not committed to the repository:

https://github.com/andreaguerr/Smatrix_4d_primal_gapped_singlet/releases/tag/integrals-refined-4d-v2026-05-15
